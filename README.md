# SimpleSocial - A Simple Social Media Platform

A lightweight, client-side social media application built with vanilla HTML, CSS, and JavaScript. Perfect for GitHub Pages!

## Features

- **Create Posts**: Share your thoughts with the community
- **Like Posts**: Show appreciation with a simple click
- **Comment on Posts**: Engage in conversations
- **User Profiles**: Set your username
- **Filter Posts**: View all posts, your posts, or liked posts
- **Responsive Design**: Works on desktop and mobile devices
- **Local Storage**: All data persists in your browser

## Live Demo

Visit the live application at: `https://[your-username].github.io/social-media/`

## How to Use

1. **Change Username**: Click "Change User" in the header to set your username
2. **Create a Post**: Type your message in the text area and click "Post"
3. **Like a Post**: Click the heart icon to like/unlike a post
4. **Comment**: Click the comment icon to expand the comments section, then type and press Enter
5. **Delete Posts**: Your own posts can be deleted using the trash icon
6. **Filter**: Use the filter buttons to view different subsets of posts

## Technology Stack

- **HTML5**: Structure and semantic markup
- **CSS3**: Modern styling with CSS variables and animations
- **Vanilla JavaScript**: No frameworks or libraries required
- **LocalStorage API**: Client-side data persistence

## Installation

### Running Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/[your-username]/social-media.git
   cd social-media
   ```

2. Open `index.html` in your web browser:
   ```bash
   open index.html
   # or
   python -m http.server 8000
   ```

### Deploy to GitHub Pages

1. Go to your repository settings on GitHub
2. Navigate to "Pages" in the left sidebar
3. Under "Source", select the branch you want to deploy (usually `main` or `master`)
4. Click "Save"
5. Your site will be live at `https://[your-username].github.io/social-media/`

## Features in Detail

### Data Persistence
All posts, likes, and comments are stored in your browser's localStorage. This means:
- Data persists across browser sessions
- Data is specific to your browser and device
- No backend server required

### Responsive Design
The app is fully responsive and works on:
- Desktop computers
- Tablets
- Mobile phones

### User Experience
- Clean, modern interface inspired by popular social platforms
- Smooth animations and transitions
- Intuitive controls and interactions

## Browser Compatibility

Works on all modern browsers that support:
- ES6 JavaScript
- CSS Grid and Flexbox
- LocalStorage API

Tested on:
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

## Privacy Note

This is a client-side only application. All data is stored locally in your browser and is never sent to any server. Data is not shared between different users or devices.
